# Item images

Drop the item PNGs here, named after the `image` field in `src/items.js`:

- `helmet.png`
- `toolcase.png`
- `starbattery.png`
- `wars.png`
- `upgrade.png`

They are attached to the timer message and render as an image below the
text — no embed involved. The bot works fine without them: a missing file just
means no attachment.

Keep them small (a few hundred pixels): Discord displays attachments at their
native size.
