# Mapping Galaxy Life

Thanks for helping! This folder does two things:

1. **It explores the galaxy map on its own.** It types coordinates, clicks each
   galaxy, takes a photo of the window that opens, closes it, and moves on.
2. **It reads the player names on those photos**, so we learn who lives where.

It does not play the game, never touches your account, and sends nothing
anywhere. Everything stays on your computer, in a `data` folder it creates by
itself.

You do not need to know anything about programming. You will type a few lines
into a black window, and that is all.

---

## Step 1 — Install two programs (once, about 10 minutes)

**a) Python** — the language these scripts are written in.
Download it from [python.org/downloads](https://www.python.org/downloads/) and
run the installer.

> **Important:** on the first screen, tick the box
> **"Add python.exe to PATH"** at the bottom, *then* click "Install Now".
> If you miss it, nothing will work later.

**b) Tesseract** — the text reader that recognises names on the photos.
Download the Windows installer from
[github.com/UB-Mannheim/tesseract/wiki](https://github.com/UB-Mannheim/tesseract/wiki)
(the file named `tesseract-ocr-w64-setup-....exe`) and keep every default
option, especially the install folder.

**c) Restart your computer.** This makes Windows notice both programs.

## Step 2 — Open the black window in this folder

1. Open File Explorer and go to this folder (the one holding `README.md`).
2. Click once in the address bar at the top, type `cmd`, and press Enter.

A black window opens, already pointing at this folder. **Every command below is
typed there**, then Enter. This is the "terminal".

Now install the small libraries the scripts need — copy and paste this line:

```
pip install -r requirements.txt
```

It prints a lot of text for a minute. When your cursor is back, it is done.

## Step 3 — Your area of the map

The map is huge, so we split it: Noé scans one band, you scan another, and we
do not photograph the same galaxies twice.

Open `config.json` with Notepad (right-click → Open with → Notepad). Find:

```json
"zone": { "x_min": 0, "x_max": 1408, "y_min": 700, "y_max": 1408 },
```

Those numbers are already set for you — **you do not have to change anything**.
Just do not edit this file unless Noé asks you to.

## Step 4 — Check that the clicks land correctly (2 minutes, once)

The script clicks at fixed places in the game window. Those places were set on
Noé's screen, so we must check they work on yours.

1. Start Galaxy Life **in a window** (not full screen) and go to the galaxy map
   view — the one where you can type coordinates.
2. In the black window, type:

```
python 1_scanner.py --test
```

3. Look at the game for the next 30 seconds. **Do not touch your mouse or
   keyboard.** The map should move, a galaxy window should open, then close.

- **If it works:** great, go to step 5.
- **If it clicks in the wrong place:** press `Ctrl` and `C` together in the
  black window to stop it, then tell Noé. Send him a screenshot of your game
  window: run `python outils\calibrer_ecran.py`, click on the game, press the
  `c` key, then `Esc`. The picture lands in
  `data\scan\ecrans_de_reference`.

## Step 5 — Scan (this is the long part)

```
python 1_scanner.py
```

- **Do not touch the mouse or the keyboard while it runs** — the script is
  using them. Best done at night, or while you are away.
- To stop it: click the black window, press `Ctrl` and `C`. Nothing is lost.
  Next time you start it, it continues exactly where it stopped.
- Photos pile up in `data\captures\1_a_traiter`. Each is about 77 KB, so a
  full night is roughly 1 GB.

## Step 6 — Read the photos

```
python 2_lire_captures.py
```

This takes about ten seconds per photo, so start it and go do something else.
You can stop it with `Ctrl` + `C` and restart it later; it picks up where it
left off.

It sorts every photo into one of two folders:

- `data\captures\2_validees` — every name on that photo was recognised;
- `data\captures\3_a_verifier` — at least one name was not certain. Next to the
  photo there is a `..._ENTOURE.png` copy with the unread names circled in red.

**Most photos will land in `3_a_verifier`, and that is normal.** A busy galaxy
holds 12 players; the reader gets about two names out of three, so a full house
almost always has one or two it is unsure about. Nothing is lost: every name it
did recognise is saved, and Noé goes through the circled ones by hand.

The script never invents a name. When it is unsure, it says so instead of
guessing.

**What you get:**

| File | What is inside |
|---|---|
| `data\resultats\joueurs_trouves.txt` | the simple list: one player and their coordinates per line, e.g. `Myra 336,7` |
| `data\resultats\systems_resolus.jsonl` | the same thing with all the details, for Noé's database |
| `data\journaux\lecture.txt` | photo by photo, what was read |

## Step 7 — Send it to Noé

Zip these two and send them over (Google Drive, WeTransfer, anything):

- the folder `data\captures`
- the folder `data\resultats`

No need to send `data\joueurs` — he already has it.

Once he confirms he received everything, you can delete `data\captures` if you
need the disk space back.

## If something goes wrong

| What you see | What it means |
|---|---|
| `'python' is not recognized` | Python was installed without "Add to PATH". Reinstall it and tick that box. |
| `Galaxy Life n'est pas ouvert` | The game must be running, in a window, on the map view. |
| `tesseract is not installed` | Step 1b was skipped, or the computer was not restarted. |
| `Dictionnaire absent` | The player list is missing from `data\joueurs`. Ask Noé to resend the folder. |
| The clicks land in the wrong place | Your game window is a different size. See step 4. |
| Lots of photos in `3_a_verifier` | Normal. See step 6. |

Some messages are in French, since the scripts were written for Noé. The ones
that matter are in the table above.

## How long things take

| | |
|---|---|
| Installing (steps 1 to 3) | about 15 minutes, once |
| Scanning | as long as you let it run; a night gives ~7 000 photos |
| Reading the photos | about 10 seconds per photo, can run while you do other things |

## What this folder does *not* contain

No passwords, no access to Noé's database or Discord bot. The only thing that
ever leaves your computer is a request for the game's public list of player
names, and only if you run `0_liste_des_joueurs.py` — which you do not need to,
the list is already included.
